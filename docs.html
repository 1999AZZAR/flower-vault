[01] ARCHITECTURAL_OVERVIEW

Flower Vault is an archival procedural botany synthesis engine developed by Azzar Budiyanto, expanding upon the foundational botanical mathematics designed by Lingdong Huang (nonflowers). The engine synthesizes morphologically coherent angiosperms and gymnosperms in the traditional Gongbi (工笔) fine-brush watercolor tradition, combining rational Bézier splines, 3D Euler rotations, Perlin pigment percolation, and deterministic taxonomic metadata recovery.

Each specimen is assigned an immutable Accession ID (e.g. FLV-7F-3K9X1A) generated via a 32-bit FNV-1a hashing function. The engine guarantees deterministic reproducibility: injecting the identical narrative phrase or Accession ID reconstitutes the exact habit, venation network, corolla geometry, and chromatic pigment washes across independent compute environments.

[02] DETERMINISTIC_PIPELINE

The synthesis cycle executes across four strictly ordered stages:

PHASE_01: INJECTION & HASHING
Arbitrary narrative strings are passed to a modified 32-bit FNV-1a non-cryptographic hash function yielding an unsigned integer seed between 1 and 2,147,483,646.
PHASE_02: TAXONOMIC DERIVATION
The seed deterministically derives the plant habit (Woody vs Herbal), binomial taxon name (Genus + Species), botanical family, foliar venation pattern, and floral merism.
PHASE_03: PROCEDURAL MORPHOLOGY
Spline skeletons are generated with 3D coordinate transformations. Foliage polygons are populated with primary and secondary venation ribs, followed by calyx sepals, multi-whorl petals, and golden stamens.
PHASE_04: GONGBI CHROMATOGRAPHY
Multi-pass alpha percolation simulates mineral pigments over xuan paper. The final specimen plate is framed with Swiss-Archival drafting borders, metric scale bar, vermilion seal chop, and cursive binomial lettering.

[03] BOTANICAL_HABITS_AND_TRAITS

The engine distinguishes four morphological growth architectures:

HABITUS WOODY SUFFRUTICOSE (ARBORESCENT / LIGNEOUS):

Features bifurcating lignified stems with secondary cambial thickening. Bark texture is synthesized using multi-stroke charcoal strokes. Petioles emerge from nodes at staggered phyllotaxis angles. Flowers are distributed along terminal branches with variable nodding angles.

HABITUS HERBAL CAULINE (HERBACEOUS):

Exhibits soft succulent petioles radiating from basal or acaulescent nodes. Foliage features broader lamina surface area with delicate reticulate or parallel venation. Scapes support corymbose cymes or solitary blossoms.

HABITUS SCANDENT LIANA & ALPINE ROSETTE:

Scandent lianas feature hanging pendant racemes and twining tendrils; alpine rosettes cluster compact fleshy basal leaf cushions supporting dense umbellet fascicles.

[04] EMBED_AND_IFRAME_PROTOCOLS

Flower Vault supports headless and distraction-free iframe embeds via the ?mode=embed query parameter. In this mode, all GUI controls, navigation headers, and control bars are stripped, leaving only the pure specimen canvas and the centered fullscreen expand control.

IFRAME EMBED MARKUP:

<iframe 
  src="https://flower-vault.glassgallery.my.id/?mode=embed&narrative=Alpine+Flora&chroma=carmine&w=4&h=5"

  height="750" 
  style="border: 1px solid #DDD5C5; background: #EFE9DC;"

POSTMESSAGE BIDIRECTIONAL PROTOCOL:

Parent applications can remotely control the embedded specimen engine via window.postMessage: 

// Instruct embedded vault to synthesize by narrative and pigment:
iframeEl.contentWindow.postMessage({
  type: 'UPDATE_SPECIMEN',
  data: { narrative: 'Nocturnal Jasmine of the East', chroma: 'wisteria' }
}, '*');

// Listen for specimen telemetry events:
window.addEventListener('message', (event) => {
  if (event.data?.type === 'SPECIMEN_SYNTHESIZED') {
    const { id, taxon, family, habit, metrics } = event.data.data;
    console.log('Specimen mounted:', id, taxon, family, habit);
  }
});

[05] SPECIMEN_PLATE_PURITY_AND_EXPORTS

The specimen plate adheres to strict Swiss-Archival herbarium monograph standards. In-canvas debug labels are eliminated in favor of clean technical stamps:

  • DUAL DRAFTING BORDERS: Dual hairline framing rules following the Swiss-Archival standard.
  • BOTTOM-LEFT: Technical metric drafting scale bar (20mm rule, natural scale 1:1).
  • BOTTOM-CENTER: Engraved cursive Latin binomial name rendered via Hershey vector cursive glyphs.
  • BOTTOM-RIGHT: Vermilion cinnabar seal chop (朱砂印章 · 草木典藏).

Both export formats are production-grade:

ARCHIVAL PNG (300 DPI)

High-resolution 2400px raster render featuring mineral pigment gradients, paper grain percolation, drafting borders, scale bar, seal chop, and typography.

STANDALONE VECTOR SVG

Self-contained SVG plate containing high-res raster botanical canvas, vector drafting borders, metric scale bar, vermilion seal chop, and authentic Hershey vector cursive curves.
