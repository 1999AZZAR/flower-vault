ARCHIVAL BOTANY MONOGRAPH & ENGINE SPECIFICATIONS

01. ARCHIVAL_BOTANY_OVERVIEW

Flower Vault is a procedural botanical synthesis engine and digital herbarium plate repository designed for structural clarity and botanical authenticity. Adapted from Lingdong Huang's nonflowers (2018), it recreates the aesthetic of Chinese Gongbi watercolor paintings and classical natural history monographs.

02. PROCEDURAL_PHYLOGENY_LOGIC

Every specimen is synthesized deterministically from narrative input via an immutable pipeline: Narrative Sequence → FNV-1a Hash → Seed → Accession ID (FLV-XX-XXXXXX) → Botanical Binomen Parameters govern branching depth, rational Bézier curvature, node phyllotaxy, and petal counts. The entire accession can be losslessly recovered bidirectional from its ID.

03. EMBED_INTEGRATION_PROTOCOL

Using the ?mode=embed parameter, Flower Vault strips all chrome and renders a pure, distraction-free specimen plate. External applications can control the engine in real-time via the postMessage API.

04. PROGRAMMATIC_ACCESS_SDK

The engine exposes full client-side and server-side JavaScript access via window.FlowerDraw without external dependencies. Developers can synthesize specimens, extract morphometrics, and generate archival plates programmatically.
