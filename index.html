01. ARCHIVAL_BOTANY_OVERVIEW

Flower Vault is an archival procedural botany synthesis engine and digital herbarium plate repository designed for technical minimalism and structural honesty. Adapted from Lingdong Huang's nonflowers (2018), it recreates the aesthetic of Chinese Gongbi watercolor paintings and classical natural history monographs.

02. PROCEDURAL_BOTANY_LOGIC

By injecting narrative sequences into the matrix, the engine hashes the input to determine plant habit (Woody vs. Herbal), foliar venation, corolla merism, and pigment washes. Every specimen is an immutable archival record, traceable via its accession identifier (e.g. FLV-B9-03S1UJ) and memory pointer hash.

03. ARCHIVAL_EXPORT_PROTOCOL

Specimens can be exported as high-resolution standalone SVG or 300 DPI PNG files adhering to the Swiss-Archival design system. The system employs an organic paper grain and framing stamps to mimic 300gsm cold-press xuan paper, ensuring visual consistency across digital and physical mediums.

04. EMBED_INTEGRATION_PROTOCOL

Flower Vault functions as an embeddable service. Utilizing the mode=embed URL parameter, the interface is reduced to a strictly archival specimen view with a bone-colored background, optimized for iframe integration. Developers can control the synthesis engine in real-time via the postMessage API.

05. PROGRAMMATIC_ARCHIVAL_ACCESS

The engine exposes zero-dependency JavaScript access via window.FlowerDraw. Developers can synthesize botanical specimens, extract morphometrics, and generate archival plates programmatically in Node.js or client-side environments.
